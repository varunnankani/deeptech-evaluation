# Varun Nankani | DeepTech Thesis

Static investment-thesis microsite covering Octobotics and PierSight.

## Files

- `index.html` - homepage
- `octobotics.html` - Octobotics deep dive
- `piersight.html` - PierSight deep dive
- `styles.css` - all site styling
- `questions.js` - guided question library
- `app.js` - question browser and page interactions
- `.nojekyll` - keeps GitHub Pages from applying Jekyll processing

## Deploy on GitHub Pages

1. Create a new public GitHub repository.
2. Upload **all files in this folder directly to the repository root**. Do not upload the parent folder itself.
3. Commit the files to the `main` branch.
4. Open **Settings -> Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select **main** and **/(root)**, then Save.
7. Wait for the `pages build and deployment` workflow to finish.
8. Your site will be available at `https://<github-username>.github.io/<repository-name>/`.

No backend, API key, build process, package manager, or environment variables are required.
